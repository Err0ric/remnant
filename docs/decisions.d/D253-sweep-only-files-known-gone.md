| D253 | The 30-day sweep of read positions removes a record only when its file is known to be gone (owner, 2026-11-14; amends D250 and ADR-0051 row 8, found in the review of #587): the folder the file was last seen in is there, on the device the file was on, without the file, and the source lists without an error. A share that is not mounted, or a folder that is away, keeps its records, or all its files would be read again and stored twice when it returns. On a system whose device numbers change, dead records under an old number are not swept; a record is used only when the content matches, so they are harmless. Also decided: the 30 seconds of D252 count from the first read to the file's end and do not restart when it grows | Accepted |
