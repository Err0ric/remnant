| D230 | Grouped vendor alerts on one item (owner, 2026-11-09, ADR-0049 0b): every vendor alert ID that joins an item stays findable (a resend or severity rise on any of them finds the item). The item's page shows the ID count and the first 50; Show all pages 200 at a time through `GET /api/alerts/{id}/alert-ids`, never all at once; the Alerts list carries none. Show alert events runs `GET /api/alerts/{id}/events`: a server-built query with the item's stored keys bound as one list parameter (never a literal list in the SQL), on the item's sources and time range only, for a viewer who can read every one of them, audited `alert.events`. New external items no longer carry SQL in their detail text.
