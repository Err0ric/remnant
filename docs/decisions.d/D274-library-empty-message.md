| D274 | A library query may say what no rows means (amends ADR-0033's pack format, without editing it; owner, fix batch of 2026-11-17, P3: "When no lease is found, say: 'No DHCP lease for this address in the range. It may be a static address.' Not 'Try a wider time range'"). An optional field `empty:` on a library query: plain text, at most 160 characters, one line (no control characters, NEL, or line and paragraph separators), no markup, template braces, or Markdown characters (`*`, `_`, `~`, backticks, brackets), checked at pack load (a pack that breaks it is refused and logged, the rest load). User packs may use it: D266 restricts `builtin`, not text. `GET /api/library` returns it. It replaces the generic empty text when that query returns no rows: in Logs while the query opened from Library is unchanged or only its parameters' values are (another address, the same at every place a parameter is used); after any other edit the generic text shows. In Ask AI's library answer it shows once: as the headline, or after what was read in the "What was counted" line when that line is the answer. Shown as a text node, never sent to a model. `who_had_ip` says "No DHCP lease for this address in the range. It may be a static address." (Palo Alto pack 1.2.0). Ask's library suggestions with no AI provider open in Logs as typed SQL, so they show the generic text | The pack format had no per-query empty message, so a lookup with no answer told people to widen the range | Accepted by the owner 2026-11-18 (Owner instruction 2026-11-17) |
