| D245 | No account, no access, on every bind (owner, 2026-11-12, for audit 2026-11 H1; amends ADR-0001 item 1): the no-sign-in mode of a loopback install with no accounts is removed. With no accounts the server is setup-only everywhere, and the first administrator is always made with the one-time link. Why: on a loopback bind behind a same-host reverse proxy every request arrives from 127.0.0.1, so nothing tells the network from the person at the machine, and anyone who could reach the proxy was the administrator. The link is in the server log at every start and from `app-admin setup-link` on the server (stored as a hash in `meta.sqlite`, single use, 30 minutes; a new one replaces the last). A loopback link opens on the machine itself, or from another computer through an SSH tunnel (`docs/install/tls.md`). For an install that ran without sign-in: its saved searches, schedules, dashboards and alert items owned by `local` become the first administrator's when that account is made, and until then its schedules keep running and its telemetry senders keep delivering (the source token is checked, as always). Amended the same day (owner): a valid, unexpired link passes the per-address limit on link redemption, so wrong links sent through a proxy that hides client addresses cannot keep the real setup out; wrong and expired links still count against the limit, and the compare stays constant-time. | Accepted 2026-11-12 (owner) |
