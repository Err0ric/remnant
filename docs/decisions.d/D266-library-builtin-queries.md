| D266 | Library builtins (amends ADR-0033; fix list 2026-11-16 item 20). Packs are plain SQL. A pack shipped with the product may name a builtin from a fixed registry in code when plain SQL cannot follow live data; the one builtin, `ai_services`, is the AI usage Services count with the live AI service catalog, so Ask's "Which AI services are people using?" equals AI usage for the same window and sources. Never in other packs (refused at load, logged, the rest load). Always through the guard on the caller's view, audited. Held SQL that Ask runs by id is not held to the 20,000-character typed-SQL limit; where it would become typed SQL (Logs, saved searches), the app says plainly that it is too long. A saved copy keeps the SQL as built when saved | The catalog lives in the metadata database, which guarded SQL cannot read, so a pack file cannot follow an admin's own services or approvals | Approved by the owner 2026-11-16 |
