| D220 | Auditor role and SQL (owner, 2026-11-08): an Auditor runs no SQL by default. Auditors keep the audit log, dashboards, and reports (read-only views of results others ran under their own permissions); Logs SQL, Ask, saved-search runs, export of query results, the CLI `query`, and the MCP server refuse an Auditor unless an admin turns on the setting that grants Auditors SQL, which is off on new and existing installs. Turning it on or off is an audited admin change. When on, an Auditor's SQL runs on the same per-session `events` view, guard, and scope as any other user | Accepted 2026-11-08 (owner) |
