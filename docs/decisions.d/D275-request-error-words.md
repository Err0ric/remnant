| D275 | The words for a request that failed on the way, and when the banner shows (owner, fix batch of 2026-11-17, P1 item 4: "Errors: a 502, 503 or 504 on any request shows 'The request took too long' (or 'The server is busy'). Show 'Can't reach the server' only when the network request itself fails."). In the app's one API client, an answer of 502 or 504 that does not carry the server's own error code (a proxy or gateway answered) says "The request took too long", a 503 without the server's code says "The server is busy", and a request that got no answer at all says "Can't reach the server"; the server's own coded answers keep their words (a busy model, the model time limit). The F40 banner now shows only for a request that got no answer, no longer for a proxy's 502, 503, or 504 (amends D88), and a request cancelled in the page is neither. Ask AI no longer holds a request open while the model works (D269), so a proxy's time limit does not end a question | A slow request behind a proxy must not read as a server that is down | Accepted by the owner 2026-11-18 (Approved by the owner 2026-11-17) |
