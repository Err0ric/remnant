| D278 | The built-in address resolution (`search/addresses.py`: People & devices, the person and address pages, AI usage) reads DHCP "lease ended" lines as well as "lease started" lines, with the rules of the library query `who_had_ip` (D272) where they apply, and lines in its order (a start before an end in the same second): a lease runs from its start line until its machine's end line, the next start on the address, or 24 hours, whichever is first; an end line while another machine's lease runs ends nothing; an end line with no lease running covers back to the later of the address's previous line and 24 hours before it. So an hour resolves the same whatever the range, as long as the lines within 24 hours of it are read: the point lookup (`/api/addresses/{ip}`) reads 24 hours on each side of its time. Both read a DHCP line with the same SQL expressions (`DHCP_IP`, `DHCP_HOST`, `DHCP_MAC`, `DHCP_ENDED`), which the library query embeds verbatim and a test holds equal; a second test holds the two to the same machines and times on a synthetic lake.
