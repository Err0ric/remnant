# Example saved searches

Import any of these on **Saved searches > Import**. Each is described in [docs/searching.md](../../docs/searching.md#example-saved-searches).

The two DHCP searches expect Palo Alto system log lines such as `DHCP lease started ip 10.20.1.5 --> mac 00:00:5e:00:53:0a - hostname LAPTOP-A, interface ethernet1/2`. That wording comes from vendor documentation: check it against a real lease line before relying on the device names.
